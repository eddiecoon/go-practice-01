## Окружение

- Операционная система: Windows.
- Версия Go: `go version go1.27.2 windows/amd64`.
- Редактор: Visual Studio Code.

## Выполнено

Шаги 1–5 практической работы № 3:

- Создана структура `Task` с полями ID, название, статус и приоритет.
- Реализован метод `Summary` для получения описания задачи.
- Реализованы методы `Complete` и `SetPriority` с получателем-указателем.
- Добавлена проверка допустимого приоритета от 1 до 3.

- Добавлен подсчёт завершённых задач.
