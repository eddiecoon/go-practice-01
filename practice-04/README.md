# Практическая работа № 4. Интерфейсы, ошибки и консольное приложение

Курс «Бэкенд-разработка на языке Go».

## Окружение

- Операционная система: Windows.
- Версия Go: `go version go1.27.2 windows/amd64`.
- Редактор: Visual Studio Code.

## Выполнено

Шаги 1–6 практической работы № 4:

- Создан интерфейс `TaskStore` и реализовано хранилище `MemoryStore`.
- Реализованы методы добавления, поиска, завершения, удаления и получения списка задач.
- Добавлена проверка названия и приоритета задачи.
- Реализована обработка ошибок с использованием `error`, `%w` и `errors.Is`.
- Создано консольное меню с обработкой некорректного ввода.
- Добавлено сообщение о завершении работы через `defer`.
- Метод `List` возвращает копию среза для защиты данных хранилища.

Данные хранятся в памяти и не сохраняются после завершения программы.

## Запуск программы

Из корневой папки проекта:

```text
go run ./practice-04/task-cli
```

Команды меню:

- `1` — добавить задачу.
- `2` — показать список задач.
- `3` — завершить задачу по ID.
- `4` — удалить задачу по ID.
- `0` — завершить работу.

## Проверка сборки и оформления

## Проверенные данные

- Вывод пустого списка и добавление задач с корректными данными.
- Отклонение пустого названия, названия из пробелов и приоритетов 0 и 4.
- Ошибки добавления не расходуют ID, удалённые ID не используются повторно.
- Завершение задачи, включая повторное завершение.
- Поиск, завершение и удаление по отсутствующему ID.
- Удаление задачи и повторная попытка её удаления.
- Обработка неизвестной команды и нечислового ввода.
- Корректный выход по команде `0` и при завершении ввода.
- Распознавание `ErrNotFound` через `errors.Is`.
- Изменение результата `List` не влияет на внутренний список задач.
